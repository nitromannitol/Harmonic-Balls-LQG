# Integrable-density transposed Green duality

This deterministic infrastructure proves signed Fubini duality for an
integrable measurable source density on a finite measure carried almost
everywhere by a bounded open planar domain, and a measurable observer bounded
almost everywhere for restricted volume. It supplies product integrability,
both relevant unweighted slices, both weighted slices, and integrability of
both outer pairings. The kernel is `greenFunction V y x` throughout.

The proof uses the existing integrable-density product estimate, the unweighted
Green product estimate, almost-everywhere bounded multiplication, and signed
Fubini. No new literature premise or reciprocity is used. This does not close a
numbered paper result. The potential-theoretic infrastructure uses work of
Leonardo Bonanno. Printed axioms: `propext`, `Classical.choice`, `Quot.sound`.
