# General-domain observation correction audit

For an open bounded domain and a finite source concentrated on a compact
subset, the pointwise theorem constructs one harmonic correction for every
observer in the domain whose source diagonal is uncharged and for which the
literal transposed Green and Newton kernels are source-integrable. It uses the
compact-pole balayage representative, including the empty compact set, and
integrates the off-diagonal identity. Newton symmetry is used only to identify
the whole-plane potential; no Green reciprocity is assumed.

The local upper-growth theorem combines that pointwise result with the
source-dependent observation null set for kernel integrability and atoms.
The I2 specialization has one probability-one event uniform in domains and
sources, followed by an observation null set that may depend on each domain
and source. The results are analytic helpers and do not close a numbered
result or assert bounded-test membership.

The three printed axiom sets contain only `propext`, `Classical.choice`, and
`Quot.sound`. The implementation has no forbidden proof placeholders or
additional literature inputs.
