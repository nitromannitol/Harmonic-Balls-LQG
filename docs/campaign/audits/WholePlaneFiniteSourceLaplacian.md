# Whole-plane finite-source Laplacian

`hasLaplacian_wholePlane_greenPotential` proves that the literal whole-plane
Green potential of a finite measure concentrated on a compact set has
`HasLaplacian (greenPotential univ ν) 0 ν univ`. This includes local
integrability and permits atoms, with no reciprocity or distributional
identity hypothesis.

On each disc containing the source, the almost-everywhere disc correction
identity transfers the sum of the disc potential and its harmonic correction.
The disc potential has the required distributional Laplacian, and the
correction has zero distributional Laplacian. Enlarging the disc around each
point establishes local integrability; enlarging it around each test
function's compact support establishes the global identity. The argument
preserves the literal kernel and totalized Bochner-integral semantics.

This analytic result does not close a numbered result. The potential-theoretic
infrastructure uses work of Leonardo Bonanno.
