# Section 5 general-domain infimum semantics

Scope: `supersolutionsOn`, `leastSupersolutionOn`, `clusterOn` in Draft/Section5.lean:103–115, compared with corrected TeX 581–593 and 1014–1025 (C21 places the pole in U). This is a definition audit, not a closure claim for Lemma 5.8. The source specifies continuous functions on the closed ball and the pointwise infimum; its general-domain sentence says the construction extends essentially verbatim to bounded open sets. No boundary convention for irregular points is specified there.

For bounded U and nonnegative t, `zero_mem_supersolutionsOn` (Proofs/Sec5/IrregularLeastSupersolution.lean:11) gives a competitor. For x in closure U distinct from z, the obstacle is a finite lower bound on every value. Audit/Section5InfimumSemantics.lean:14 proves that the frozen real sInf is the actual greatest lower bound; :27 gives the full lower-bound characterization and :41 gives approximation from above. In particular :53 proves equality, after coercion to EReal, with the complete extended-real infimum of the same competitor values. This applies at all interior and boundary points except the pole, without assuming admissibility of the infimum or regularity of U. It establishes the order semantics conditional on the frozen competitor class and Green function; it does not establish that those classes coincide with every possible interpretation of the source on irregular boundaries.

At the pole, Defs/Green.lean:65–74 sets the diagonal Green value to zero, whereas the source Green function has its logarithmic +∞ singularity. Draft/Section5.lean:103 excludes the pole from the obstacle constraint, so it does not accidentally require w(z) ≥ 0. Draft/Section5.lean:114 explicitly inserts z into the cluster when z ∈ U. This agrees with the source strict inequality at the pole provided the source infimum is finite there and t > 0, but the real sInf's finiteness is not established by the off-pole argument. The precise open obligation under the intended local-finiteness and volume-growth hypotheses is:

```
BddBelow ((fun w : ℂ → ℝ => w z) '' supersolutionsOn μ U z t)
```

for open bounded U, z ∈ U, t > 0 and the applicable enclosing-disc `VolumeGrowth μ R βm βp`. Nonemptiness already follows from zero. A proof needs a uniform lower bound on all competitor values at z, not merely continuity of each competitor separately. If this bound holds, `isGLB_csInf` gives the pole characterization and the same EReal argument as :53 applies. If it fails, real `sInf` uses 0 while the extended infimum is −∞; no such failure is asserted here. The proof for Green-regular domains (Proofs/Sec5/GreenRegularDomainAdmissibility.lean:543) uses stronger boundary hypotheses and does not discharge this general obligation.

Independently of that value, :81 proves the exact set identity: the cluster closure is the union of `{z}` with the closure of the strict off-pole noncontact set. Thus explicit insertion changes that closure precisely when z is not already in the latter closure. It does not by itself prove that z is an accumulation point or validate the source pole convention. The comparison in Audit/Section5ExhaustionCompatibility.lean uses explicit insertion, so this finding does not invalidate its conditional Lean equality.

Outside closure U the frozen functions have an additional ambient carrier ℂ → ℝ which the source C(closure U) does not have. In fact, for open bounded U, t ≥ 0, and x outside closure U, start with the zero competitor and change its value at x to any real number. The restriction to closure U and Laplacian on U are unchanged, so all real values occur. The real sInf is consequently its unbounded-below junk value 0, while the extended infimum is −∞. This is a concrete public-carrier mismatch, not a mismatch on the source carrier; no cluster point lies outside U.

For an irregular boundary point y ≠ z the Lean Green function is set to zero outside U (Defs/Green.lean:100), hence every competitor has w(y) ≥ 0 and the least value is 0 (IrregularLeastSupersolution.lean:19). This is a definite boundary convention; the TeX's verbatim extension does not explicitly resolve whether the pointwise zero extension or a limiting Green boundary value is intended. The distinction matters: `not_mem_supersolutionsOn_finset_punctured_of_compact_containment` (Proofs/Sec5/FinitePunctureAdmissibility.lean:139) shows under its explicit locally finite, volume-growth, puncture and containment hypotheses that the infimum is not a supersolution. No arbitrary-domain boundary continuity or admissibility may be inferred.

Verdict: off-pole real/extended order semantics PASS for the frozen competitor class on closure U; outside-carrier values differ concretely; pole lower boundedness and source interpretation at irregular boundary remain UNDECIDED. BODY_MATCH and full PUBLIC_CARRIER/CHARACTERIZATION remain fail-closed, including the independent Green-function and field/measure semantics noted in the exhaustion audit.
